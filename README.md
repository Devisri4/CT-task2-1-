## 🔧 How It Works

1. Code is pushed to the `master` branch.
2. GitHub Actions (via `deploy.yml`) automatically runs the deployment job.
3. The job uses the `peaceiris/actions-gh-pages` action to publish the content to GitHub Pages.
4. Your HTML site becomes live at the specified GitHub Pages URL.
